# cifrax-legal

Documentos legales públicos de **Cifrax** — navegador de privacidad para Android.

Este repositorio aloja, mediante **GitHub Pages** (servido desde la carpeta `/docs` de la
rama `main`), las páginas que enlaza la ficha de Google Play:

- **Política de Privacidad** — [`/docs/privacy-policy.html`](docs/privacy-policy.html)
- **Términos del Servicio** — [`/docs/terms-of-service.html`](docs/terms-of-service.html)
- **Landing** — [`/docs/index.html`](docs/index.html)

Páginas HTML autocontenidas (sin CDN ni dependencias externas), tema oscuro, responsive.
